# Desejos

Lista de desejos para abrir no navegador do celular e "Adicionar à Tela de Início".
Site estático (HTML/CSS/JS, sem build), publicado pelo GitHub Pages. Tudo fica salvo no próprio aparelho
(dados no localStorage, fotos no IndexedDB). Em Perfil dá para exportar/importar uma cópia de segurança.

- Categorias, visão de tudo e dos comprados
- Item com foto, descrição, etiquetas, prioridade (alta/média/baixa) e ordem manual
- Lojas/sites com preço: tabela comparativa destacando o melhor preço
- Finanças: dinheiro de hoje, quanto guarda por mês, metas e plano de quando dá pra comprar cada item

Ao mudar qualquer arquivo, aumente `VERSAO` em `sw.js`.
